# Capri — Python Desktop Companion

Портативное desktop-приложение (Windows) с персонажем Капри из Cyberpunk: Edgerunners 2.

## Стек
- Python 3.10+ + PyQt6 (окно, анимации, UI)
- Pillow (обработка спрайтов)
- psutil (метаданные системы/процессов)
- Rule-based диалоги (без ИИ/LLM)
- Полностью автономное (без интернета)

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

## Сборка (Windows)
```bat
build.bat
```
Результат в `dist/Capri/`. Скопируйте папку на флешку — приложение портативное.

## Структура
```
capri/
├── main.py
├── core/          # состояние, шина событий
├── overlay/       # окно, аниматор спрайтов
├── audio/         # звуки
├── events/        # трекеры окон, бездействия, процессов, метаданные
├── dialogue/      # движок диалогов
├── files/         # менеджер, обозреватель, операции
├── assets/        # спрайты, шрифты, фразы
└── requirements.txt
```

## Взаимодействие
- Перетаскивание — ЛКМ по Капри.
- ПКМ — контекстное меню.
- Двойной клик — приветствие.
- Наведение мыши — моргание.
- Перетаскивание файла на Капри — показ метаданных.
- Все файловые операции scoped в `capri_workspace/`.

## Метаданные
- Активное окно: заголовок, PID, процесс, exe, CPU/RAM.
- Система: CPU%, RAM, диски.
- Файлы: размер, даты, sha256, превью текста.

## Диалоги
Реплики в `assets/phrases.json` и `assets/dialogue_arch.json`. Систему диалогов можно заменить — движок подхватит автоматически.
